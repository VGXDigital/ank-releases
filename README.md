# Ank (अंक)

Ank is a free text calculator for macOS from [VGX Consulting](https://vgx.digital). Write calculations as plain lines and the results line up on the right: Indian or international digit grouping, percentages, units, live currency rates, dates and timezones, variables, your own functions, and a Globals sheet shared by every sheet. It also has a quick-entry popup (⌃⌥=) and a command-line tool.

This repository holds the releases. Ank checks it for updates once a day and asks before installing one.

## Install

1. Download the latest `.dmg` from [Releases](https://github.com/VGXDigital/ank-releases/releases/latest).
2. Open it and drag Ank to Applications.
3. Ank is signed but not notarized, so open it once, then go to System Settings > Privacy & Security and click Open Anyway.

Ank needs macOS 14 or later. Next-line suggestions need macOS 26 with Apple Intelligence.
